Lithomaker

A STEM project that converts images into lithophane models for 3D printing.

What is Lithomaker?

Lithomaker is a simple web tool that converts a grayscale image into a lithophane 3D model suitable for 3D printing. When illuminated from behind, the printed lithophane reveals image details through variations in thickness.

How to use

  1. Upload an image: Choose a grayscale or high‑contrast photo. Be mindful of image size—very large images may slow processing.
  2. (Optional) Adjust image settings: Adjust brightness and contrast to enhance details and improve the lithophane result.
  3. Generate and download: Create the lithophane model and download the STL file for 3D printing.
